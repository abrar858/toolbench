    Excel to PDF converter

    Turn a sheet from an Excel or CSV file into a tidy PDF that is easy to print, email or attach to a report.

    • Free, no sign-up
    • Runs privately in your browser
    • Instant results
    ⇪Choose an Excel or CSV fileor drag and drop a file here · files stay on your device

    Choose a spreadsheet to preview it.

    In the print window, choose Save as PDF as the printer.

    How to convert Excel to PDF

    1. Choose an .xlsx, .xls, .ods or .csv file.
    2. Pick the sheet, orientation and paper size, and whether to show gridlines.
    3. Check the preview.
    4. Press Save as PDF and choose Save as PDF as the printer.

    Print-friendly by default

    Wide sheets are set to landscape, the first row repeats as a header on every page, rows are never split across pages, and cells show the values exactly as Excel displays them, including currency and date formats.

    What is not included

    Cell colours, merged cells, charts and images are not carried over. For a copy that matches your formatting exactly, use File → Save as → PDF in Excel. This tool is ideal when you don't have Excel, or want a clean, consistent layout.

    Frequently asked questions

    How do I convert Excel to PDF without Excel?

    Choose the file here, check the preview and press Save as PDF.

    How do I fit a wide spreadsheet on one page?

    Choose landscape. In the print window you can also set Scale to 'Fit to page width' in most browsers.

    Can I convert a CSV file to PDF?

    Yes. CSV files work the same way as Excel files.

    Is my spreadsheet uploaded?

    No. The file is opened by your own browser and never leaves your device, so it is safe for payroll, customer lists and other confidential data.
