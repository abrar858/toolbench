    How to convert Excel to JSON

    1. Choose an Excel or CSV file.
    2. Pick the sheet and the JSON shape: an array of objects or an array of rows.
    3. Choose 2 spaces, 4 spaces or minified.
    4. Copy the JSON or download it as a .json file.

    Worked example

    A sheet with the header row Name | Age and a row Sam | 34 becomes [{"Name": "Sam", "Age": 34}] as an array of objects, or [["Name", "Age"], ["Sam", 34]] as an array of rows. Numbers and true/false values keep their type, dates become ISO 8601 text such as 2026-04-06T00:00:00.000Z, and empty cells become null.

    Tips

    Use short, unique column headings without spaces if the JSON is going into code. To check or reformat the output, paste it into the JSON formatter.

    Frequently asked questions

    How do I convert Excel to JSON?

    Choose the file, keep 'Array of objects' and copy or download the JSON.

    Which row becomes the keys?

    The first row of the sheet. Choose 'Array of rows' if your sheet has no header.

    Can I convert CSV to JSON too?

    Yes. CSV files work the same way.

    Is my spreadsheet uploaded?

    No. The file is opened by your own browser and never leaves your device, so it is safe for payroll, customer lists and other confidential data.
