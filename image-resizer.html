    How to resize an image

    1. Choose one or more images.
    2. Pick Width and height or Percentage.
    3. Enter a width, a height or both. With Keep proportions on, the image fits inside that size without stretching.
    4. Press Resize, then download the images.

    Common sizes

    • Full HD: 1920 × 1080 pixels
    • Instagram square: 1080 × 1080; portrait 1080 × 1350
    • Profile pictures: 400 × 400
    • Email-friendly photos: 1200 pixels wide
    • Passport-style photos for online forms: check the form, often 600 × 750

    Keep proportions

    With Keep proportions on, the image is scaled to fit inside the width and height you enter, so nothing is stretched. Turn it off to force an exact size; the picture will be stretched or squashed if the shape is different. Enter only a width or only a height and the other side is worked out for you. To crop to an exact shape first, work out the size with the aspect ratio calculator.

    Pixels, file size and DPI

    Resizing changes the number of pixels, which is what decides how sharp an image looks and, with compression, how big the file is. The DPI (dots per inch) setting only tells a printer how large to print it: a 3000-pixel-wide image prints 10 inches wide at 300 dpi or 20 inches wide at 150 dpi, with exactly the same file. To make a file smaller to upload, reduce the pixels here or use the image compressor.

    Making images bigger

    Enlarging spreads the same detail over more pixels, so a small image made bigger looks soft. Up to about 150% usually looks fine; beyond that, start from a larger original if you can.

    At 300 dpi prints look sharp up close. For posters seen from a distance, 150 dpi is usually enough, which halves the pixels needed on each side.

    Frequently asked questions

    How do I resize an image to specific dimensions?

    Choose Width and height, enter the pixel size, turn off Keep proportions if it must be exact, and press Resize.

    Does resizing reduce file size?

    Yes. Smaller dimensions mean fewer pixels and a smaller file. For even smaller files use the image compressor.

    Can I make an image bigger?

    Yes, up to 400% or 16,384 pixels, but enlarging can't add detail, so it may look soft.

    Are my files uploaded?

    No. Your files are processed by your own browser and never leave your device. Nothing is sent to a server, so it works for confidential documents and you can even use it offline once the page has loaded.

    How do I resize a photo for a UK passport or ID form?

    Check the form's own size rules. GOV.UK's online passport service, for example, asks for photos at least 600 pixels wide and 750 pixels tall. Enter the required size with Keep proportions ticked.
