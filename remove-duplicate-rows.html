    How to remove duplicate rows

    1. Choose an Excel or CSV file and pick the sheet.
    2. Choose the columns that must match for two rows to count as duplicates. For example, just the email column.
    3. Optionally ignore upper and lower case and extra spaces.
    4. Press Remove duplicates, check the result and download it as Excel or CSV.

    Which rows are kept

    The first time a row appears it is kept, and later copies are removed, so the original order of your data is preserved. The header row is always kept.

    Removing duplicates in Excel itself

    If you have Excel, you can also do it there:

    1. Select the data, including the header row.
    2. On the Data tab, choose Remove Duplicates. On Windows the keyboard shortcut is Alt, then A, then M, pressed one after another.
    3. Tick the columns that must match. To remove duplicates based on two columns, tick only those two.
    4. Press OK. Excel keeps the first copy of each row and deletes the rest from your sheet.

    To see duplicates before deleting anything, use Home › Conditional Formatting › Highlight Cells Rules › Duplicate Values. In Excel 365 and Excel 2021, the formula =UNIQUE(A2:C100) lists each distinct row in a new place and leaves the original untouched.

    This tool helps when you don't have Excel, when the file is a large CSV, or when you want to keep the original file unchanged and download a cleaned copy.

    Matching on some columns

    Two customer rows might have the same email address but different sign-up dates. Untick every column except Email to treat them as duplicates. Tick Ignore upper/lower case and extra spaces so that Sam@Example.com and sam@example.com count as the same.

    Frequently asked questions

    How do I remove duplicates in Excel?

    In Excel, select the data and choose Data › Remove Duplicates, tick the columns to compare and press OK. Without Excel, or to keep your original file unchanged, choose the file here, pick the columns and press Remove duplicates.

    What is the shortcut to remove duplicates in Excel?

    On Windows, press Alt, then A, then M, one after another, to open Remove Duplicates. On a Mac, use Data › Remove Duplicates.

    How do I remove duplicates based on two columns?

    Tick only those two columns, in Excel's Remove Duplicates or here. Rows count as duplicates only when both columns match.

    Does it change my original file?

    No. A new file is downloaded; the original stays as it was.

    Can I remove duplicates from a CSV?

    Yes, and you can save the result as CSV again.

    Is my spreadsheet uploaded?

    No. The file is opened by your own browser and never leaves your device, so it is safe for payroll, customer lists and other confidential data.
