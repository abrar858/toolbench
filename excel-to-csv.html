    How to convert Excel to CSV

    1. Choose an .xlsx, .xls or .ods file.
    2. Pick the sheet and separator. Use semicolon for software set up for European number formats.
    3. Tick Export every sheet to get one CSV per sheet in a ZIP file.
    4. Press Convert to CSV and download.

    Which separator?

    • Comma: the standard for most software and the UK and US.
    • Semicolon: used where the comma is the decimal mark, such as much of Europe.
    • Tab: safest when values themselves contain commas; saved as .tsv.

    Saving as CSV in Excel itself

    If you have Excel, you can also do it there:

    1. Open the workbook and go to the sheet you want.
    2. Choose File › Save As (on a Mac, File › Save As or Save a Copy).
    3. Under the file type, choose CSV UTF-8 (Comma delimited).
    4. Save, and say yes when Excel warns that only the current sheet is saved.

    Excel saves one sheet at a time, so a workbook with several sheets needs one Save As per sheet. This converter can export every sheet at once, and lets you choose a semicolon or tab separator. In Google Sheets, use File › Download › Comma-separated values, which also saves the current sheet only.

    UTF-8 and special characters

    The UTF-8 marker option helps Excel show £, €, accents and other characters correctly when the CSV is opened again. Turn it off only if the software you are importing into rejects it.

    Frequently asked questions

    How do I save one Excel sheet as CSV?

    Choose the file, pick the sheet and press Convert to CSV.

    How do I convert Excel to CSV in Excel?

    Use File › Save As and choose CSV UTF-8 (Comma delimited). Excel saves only the sheet that's open, so repeat it for each sheet, or use this converter to export them all at once.

    Can I export all sheets at once?

    Yes. Tick 'Export every sheet' to download a ZIP with one CSV per sheet.

    Are formulas kept?

    CSV can only store values, so the calculated results are exported, not the formulas.

    Is my spreadsheet uploaded?

    No. The file is opened by your own browser and never leaves your device, so it is safe for payroll, customer lists and other confidential data.
