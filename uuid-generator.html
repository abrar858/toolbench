    How to use the UUID generator

    1. Choose how many UUIDs you need, up to 100.
    2. Pick a format: standard with hyphens, compact without hyphens, or in braces.
    3. Generate and copy the list.

    What is a UUID?

    A UUID (universally unique identifier) is a 128-bit value written as 32 hexadecimal characters, such as 3f2b8c1e-6a4d-4f8e-9b2a-7c1d5e0f9a34. Version 4 UUIDs are random, with 122 random bits, so the chance of two ever matching is vanishingly small. They are widely used as database keys, request IDs and file names.

    UUID or GUID?

    GUID is Microsoft's name for the same thing. The braces format, such as {3f2b8c1e-…}, is common in Windows and .NET settings.

    How version 4 UUIDs are generated

    Each UUID is created by your browser’s built-in crypto.randomUUID() function, which uses 16 random bytes from the browser's cryptographic random number generator. Six bits are then fixed to mark it as version 4 and as the standard RFC 9562 variant, which is why the third group always starts with 4 and the fourth group starts with 8, 9, a or b.

    That leaves 122 random bits: about 5.3 × 1036 possible values. You would need to generate billions of UUIDs every second for many years before a duplicate became likely.

    Tip: random UUIDs do not sort by time, which can slow some database indexes. If insertion order matters, consider a time-ordered identifier such as UUID version 7.

    Frequently asked questions

    Are these UUIDs truly unique?

    They are generated with secure randomness. Duplicates are theoretically possible but so unlikely that they can be treated as unique in practice.

    What is the difference between UUID v4 and v7?

    Version 4 is fully random. Version 7 starts with a timestamp so values sort by creation time. This tool generates version 4.

    Can I generate UUIDs without hyphens?

    Yes. Choose the compact format.
