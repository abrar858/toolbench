Privacy: inputs and workflows are processed locally. Workflow settings are saved in this browser's local storage. Imported workflows contain only supported transformation steps; no arbitrary code runs. This is not a hosted n8n server: no background schedules, external webhooks or account integrations.


What you can automate
Chain text steps and run them in order on any text you paste in: trim whitespace, change case, find and replace, add a prefix or suffix, split or join lines, parse and format JSON, URL-encode or decode, Base64-encode or decode, and count words.
Example: paste a list of product names, trim them, convert to lower case, replace spaces with hyphens and add a prefix to turn them into web addresses in one click. Export the workflow as a JSON file to reuse it or share it with a colleague.
Need a single step? Use the standalone case converter, JSON formatter, URL encoder, Base64 encoder or word counter.
