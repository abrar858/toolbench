    Merge Excel files

    Combine several Excel or CSV files into one: keep each sheet as its own tab, or stack all the rows into one sheet with columns matched by their names.

    • Free, no sign-up
    • Runs privately in your browser
    • Instant results
    ⇪Choose Excel or CSV filesor drag and drop files here · files stay on your device

      Add two or more files. Use the arrows to set the order.

      How to merge Excel files

      1. Choose two or more .xlsx, .xls, .ods or .csv files.
      2. Put them in order with the arrows.
      3. Choose to keep each sheet as a tab, or stack the rows of every file into one sheet.
      4. Press Merge files and download merged.xlsx.

      Two ways to merge

      Keep each sheet as its own tab copies every sheet from every file into one workbook, renaming tabs if two have the same name. Stack the rows takes the first sheet of each file and puts the rows one after another, which is ideal for monthly reports, survey exports or sales data with the same columns.

      Header rows and source column

      When stacking, keep Files have a header row ticked so the column titles appear once at the top instead of being repeated for every file. The optional source column records which file each row came from, so you can filter by it later.

      Columns matched by name

      When stacking rows with Files have a header row ticked, columns are matched by their heading, not their position, so a file with Email before Name still lines up correctly. Upper and lower case and extra spaces are ignored. Columns that appear in only some files are added at the end and left blank for the others.

      Frequently asked questions

      What if my files have columns in a different order?

      Keep ‘Files have a header row’ ticked. Columns are matched by heading name, so the order in each file doesn't matter.

      How do I combine multiple Excel files into one?

      Choose the files, pick how to merge and press Merge files.

      Do the files need the same columns?

      Only when stacking rows. Columns are matched by position, so put them in the same order in every file.

      Can I merge CSV and Excel files together?

      Yes. You can mix .csv, .xlsx, .xls and .ods files.

      Is my spreadsheet uploaded?

      No. The file is opened by your own browser and never leaves your device, so it is safe for payroll, customer lists and other confidential data.
