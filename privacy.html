Privacy at Toolbench

Toolbench is designed so the calculations, conversions and text processing in its tools happen in your browser. The current site does not use accounts, an application database, analytics scripts or advertising trackers.

External services

The main page loads fonts from Google Fonts. Your browser may connect to Google to download those fonts; Google's own privacy terms apply to that connection. If this site is hosted on GitHub Pages, GitHub may process technical connection data such as IP addresses and server logs under its policies.

Information you enter

Tool inputs are processed in your browser and are not sent to a Toolbench application server. Avoid entering sensitive information on shared devices. Browser extensions and the device you use may have their own access.

Cookies and changes

Toolbench currently does not deliberately set tracking cookies. If advertising, analytics, accounts or additional third-party services are introduced, this notice must be reviewed before launch.

Contact

For enquiries, use the project's GitHub repository. Do not post personal information in public issues.
