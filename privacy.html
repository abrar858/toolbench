    Privacy

    ToolsBravo keeps tool inputs in your browser. Optional feedback is processed separately.

    Calculations, conversions, and files you use with the tools are processed locally in your browser. We do not receive the documents, passwords or calculator values you enter into those tools.

    Hosting and external services

    The website is hosted on GitHub Pages, which may process IP addresses and connection logs. If you choose to send feedback, your browser connects to Supabase (our feedback database and submission provider). The private administrator dashboard loads a JavaScript library from esm.sh when an administrator visits it. We do not use advertising trackers on tool pages.

    Optional feedback

    When you submit a review, bug report or feature request, we collect the selected tool, feedback category, optional rating, message and submission time. Supabase processes your submission. The server uses a temporary hash derived from connection information to limit abuse; the hash is not intended to identify you. We do not ask for your name or email in the feedback form. Please do not include personal, medical or financial information in the message. Submissions are private until reviewed and are not published automatically.

    Purpose, retention and requests

    We use feedback to improve the tools, investigate problems and moderate reviews. We retain submissions while they are needed for those purposes, subject to periodic review; a fixed automatic deletion schedule has not yet been implemented. To request deletion or raise a privacy concern, contact us through the project's GitHub repository without posting sensitive details publicly.

    Local storage and administrator login

    Your browser may store your theme choice and locally saved automation workflows. The private feedback administrator dashboard uses Supabase Authentication to manage administrator sessions; ordinary visitors do not need an account to submit feedback.

    Last updated: November 2026.
