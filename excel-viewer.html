    Choose an .xlsx, .xls, .ods or .csv file. It opens on your device; nothing is uploaded.

    How to open an Excel file without Excel

    1. Choose an .xlsx, .xls, .ods or .csv file.
    2. Switch between sheets with the tabs.
    3. Type in the search box to show only the rows that contain a word or number.

    When it helps

    Check an attachment on a computer without Microsoft Office, look up a row in a large export, or open a spreadsheet on a work machine where you can't install software. Values appear as Excel formats them, including dates and currency.

    Limits

    The viewer shows values, not formulas, colours or charts, and displays the first 1,000 matching rows of a sheet at a time. Use search to find rows further down. To edit or convert the file, try Excel to CSV or Excel to PDF.

    Frequently asked questions

    How can I open an XLSX file without Excel?

    Choose it here. It opens in your browser, on any device, with no software to install.

    Can it open old .xls files?

    Yes, as well as .xlsx, .xlsm, .ods and .csv.

    Can I edit the spreadsheet?

    No, it is a viewer. Use Google Sheets or LibreOffice to edit, or the converters to change the format.

    Is my spreadsheet uploaded?

    No. The file is opened by your own browser and never leaves your device, so it is safe for payroll, customer lists and other confidential data.
